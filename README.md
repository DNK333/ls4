# React ls4 — Счётчик товара

Учебная работа по React: передача данных через props и управление локальным состоянием компонента.

**Студент:** Магамед Вахаевич Дзангиев

## Что сделано

- Создан компонент `ProductCard`, который получает название и цену товара через props.
- В каждой карточке используется собственное состояние `count`, изначально равное `0`.
- Кнопки `+` и `−` изменяют количество; значение не опускается ниже нуля.
- На странице показаны три товара: кофе в зёрнах, тёмный шоколад и листовой чай.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
```
